# AI 生成文に混ざる語彙と構文の照合表

推敲のときに一度だけ通す照合表である。
`japanese-tech-writing` の「翻訳調の比喩と擬人化の禁止」と `SKILL.md` の「語彙」の節が判定の目安を定めており、この表はその目安に引っかかりやすい語を具体的に並べたものに過ぎない。
表にない語でも、字義どおりの動作を想像しうる述語なら同じ扱いにする。

言い換えの候補は機械的な置換表ではない。
元の文と同じ意味、同じ言い切りの強さ、同じ対象の範囲になる場合だけ使い、そうならない語は元のまま残す。
元の文から決められない点は推測で補わず、`SKILL.md` の「書き換えで変えてはいけないもの」に従って「書き手に確かめたい点」として返す。

## 1. 比喩的に使われる動詞

| 動詞                  | 見直したい用例                                     | 言い換えの候補と注意点                                                                                                                                                                                                                                                                                               |
| --------------------- | -------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **効く / 効いてくる** | 「地味に効きます」「〜が効いてくる」               | 何がどう変わるのかを書く（「目立たないながらも役に立つ」「〜が少しずつ楽になる」など。「地味に」の含みを残す）。「じわじわ助けになる」「良いほうに働く」のように、効き目や評価だけをぼんやり述べる言い方にしない。                                                                                                   |
| **壊れる**            | 「データが静かに壊れる」「設計が壊れる」           | データやシステムに対する「壊れる」は、「おかしくなる」「使えなくなる」のように同じ広さの意味を持つ言葉にする。「データの整合性が失われる」「不整合が生じる」と書くのは、元の文や前後から整合性の話だと明らかなときだけに限定し、言い切りの強さも保つ。時計や機械、身体など文字どおりの「壊れる」はそのまま残す。     |
| **倒す**              | 「〜側に倒す」「残さない側に倒す」                 | 「〜を優先する」「〜の扱いに統一する」「除外する」                                                                                                                                                                                                                                                                   |
| **溶かす**            | 「時間を溶かしました」                             | 「時間がかかってしまった」「時間を費やしてしまった」（無駄にした・かかってしまったという後悔の含みを残す）                                                                                                                                                                                                           |
| **潰す**              | 「1つずつ潰していく」                              | 「1つずつ直す」「消す」「解決する」                                                                                                                                                                                                                                                                                  |
| **踏み込む**          | 「〜まで踏み込んで」                               | 「詳しく調べる」「掘り下げる」                                                                                                                                                                                                                                                                                       |
| **引き返す**          | 「動かしながら引き返す」                           | 「元の状態に戻す」は、何をどこへ戻す意味か原文や提供文脈から明確な場合だけ使う。不明なら、動かすことと引き返すことの関係を決めずに「書き手に確かめたい点」で確認する。確認の際も「どの状態に戻すか」のように状態への復帰や行き先を決めつけず、元の語が指す動作と動かすこととの関係について、内容を限定せずに尋ねる。 |
| **添える**            | 「経路が代わりに添える」                           | 「つける」「渡す」「付加する」。対象と動作の関係が分かり、元と同じ意味になる場合のみ検討する。付け足すのか提供・伝達するのかが文脈から確定できないときは、元の動詞のまま残す。                                                                                                                                       |
| **収斂する**          | 「その価格帯に収斂した」                           | 「落ち着いた」「決まった」                                                                                                                                                                                                                                                                                           |
| **沈黙する**          | 「静かに沈黙する」                                 | 「反応しない」「応答しない」。終了したか、通知が出たかは、原文や文脈から分かる場合だけ書く。                                                                                                                                                                                                                         |
| **黙って**            | 「黙って無視される」「黙って捨てられる」           | 「気づかないうちに無視される」「知らないうちに破棄される」（仕組みとしてエラーや通知が出ないことがはっきり分かる場合に限り「エラーを出さずに」「通知なく」とする）                                                                                                                                                   |
| **逃がす**            | 「例外を上に逃がす」「処理を別のスレッドに逃がす」 | 「呼び出し元へ渡す」「別のスレッドへ移す」。何をどこへ移すのかが原文や前後から分かる場合だけ、その動作で書く。分からない場合は元の動詞のまま残す。「熱を逃がす」「魚を逃がす」のような字義どおりの用法は残す。                                                                                                       |

## 2. 英語を直訳したような構文

| _silently fail / ignored_            | 「静かに壊れる」「黙って無視される」                                                              | 「気づかないうちにデータがおかしくなる」「知らないうちに無視される」（データ等への「壊れる」は「おかしくなる」「使えなくなる」のように同等の広さの言葉にし、整合性の文脈であることが明らかな場合のみ「整合性が失われる」等とする。「静かに」「黙って」のぼかしは気づけない幅のまま直す。「通知なく」「エラーを出さずに」のように仕組みの話にするのは、元の文や前後から明らかな場合のみ）                                                                                                                                                                                                                                                                                                                                                                                                           |
| _the moment ..._                     | 「〜した瞬間」「〜した瞬間に」                                                                    | 「〜するとすぐに」「〜した時点で」                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| _single source of truth_             | 「〜を正本にする」「〜の正本として」                                                              | 原文や比較の基準、参照元など、その語が指す役割に合う言葉で書く。唯一の参照元と明示されている場合は、その限定を保つ。信頼性・唯一性・更新元という役割を新たに足さず、正式な文書を区別する「正本」は意味を保って残す。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| _point to / suggest_                 | 「〜を指している」「〜を示唆している」                                                            | 対象を指す表現と、根拠から推量する表現を区別する。「〜を示唆している」が回りくどいときは、「この結果から〜と考えられる」のように、何を根拠にどう推量しているかを平易に書く。根拠と推量の強さを保ち、「示唆する」を一律に「意味する」へ変えない。確認・周知の状態を述べる文は、その状態を落とさず、確認済みの結果を推量へ戻さない。元の表現で自然に伝わる場合は残す。                                                                                                                                                                                                                                                                                                                                                                                                                               |
| _load-bearing_                       | 「耐力のある」「構造を支える」                                                                    | 「欠かせない」「外せない」「不可欠な」                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| _it is not X, it is Y_               | 「Xではなく、Yです」「Xではない。Wでもない。Yだ。」「Xじゃない、Yです」「単なるXではなく、Yです」 | 「Xではなく、Yでもある」は否定と「も」を保って一つの文のまま残し、2文に分けたり、その意味を書き手に尋ねたりしない。単なる修辞でXを削っても通じる場合は「Yです」とする。Xと誤解されやすい点への反論や見方の切り替えを担っている場合は、否定を残して「Xではなく、Yです」と自然に整える（Aに加えてBなどに改変しない。「そのもの」等の余計な強調語は足さない）。否定を重ねる形も同じ基準で判断し、否定を残す場合は否定していた内容をすべて保つ。ただし、直前で問いなどとして挙げた二つを否定が打ち消すだけで、「どちら」が何と何を指すかが直前の文脈から一通りに決まる場合は、「どちらでもない。」（敬体なら「どちらでもありません。」）と短く受けてもよい（「どちら」が二つを指すので、内容は保たれる）。打ち消すほかに問いにない内容（強めの語、限定、なぜ違うかの説明など）を含む否定は短くしない。 |
| _delve into_                         | 「〜に深く分け入る」「深掘りする」                                                                | 「詳しく調べる」「具体的に見ていく」                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| _closure_                            | 「依存の閉包」「〜の閉包を取る」                                                                  | 「そこから参照されるものすべて」「依存しているものを全部」のように何を集めたものかを書く。数学（推移閉包、閉包演算など）や言語仕様のクロージャ（closure）を定義どおり使う場合は残す。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| _version_                            | ソフトウェアについて「この版では」「新しい版で」                                                  | 技術文書では「バージョン」と書く。「第2版」「日本語版」「無料版」「改訂版」のように出版物や製品の種類を表す定着した言い方や、仕様書の正式名称にある「版」は残す。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| _regression_                         | 「回帰が出た」「回帰を起こす」                                                                    | 技術文書では「リグレッション」「デグレ」、または「以前は動いていた〜が動かなくなった」と具体的に書く。「回帰テスト」「回帰分析」「線形回帰」など定着した用語は残す。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| _connect_                            | 論理や議論について「AとBを接続する」「次の章に接続する」                                          | 「関連づける」「つながりを示す」「一致させる」から、何と何をどうつなぐのかに合う語を選ぶ。どれも合わない場合は元の語を残す。配線、ネットワーク、データベースなどの接続は残す。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| _em dash (— / ―)、罫線 (─ / ━ / ──)_ | 「〜――とりわけ〜――は」、「速さ、軽さ、静けさ──。」                                                | 「〜、特に〜は」のように、対象と強調する範囲を保って句読点や助詞でつなぐ。末尾で余韻を持たせる列挙は「速さと軽さ、静けさを重視しました。」のように何についての列挙かを述語で言い切る。文脈から述語が分からない場合は推測で補わず、記号だけ外して並びを残し、書き手に確認する（小説・随筆で文体として使うダッシュや引用は残す）。                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |

## 3. 増えている比喩と定型

| 分類                 | 増加した語                                                                                                   | 用例                                   | 言い換えの候補                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| -------------------- | ------------------------------------------------------------------------------------------------------------ | -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **障害・失敗の比喩** | `事故` `混ざる` `落とし穴` `破綻` `実害` `素通り`                                                            | 「〜という事故」「落とし穴があります」 | `事故` は「思いがけない失敗・トラブル」、`混ざる` は「入り込む」、`落とし穴` は「見落としやすい点・気をつけたい点」、`破綻` は「うまくいかなくなる」、`実害` は「実際の困りごと」、`素通り` は「気づかず通る」                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **確認・検証の比喩** | `疑う` `断定` `取り違える` `見落とす`                                                                        | 「〜を取り違えると」                   | `疑う` は「念のため見直す・確かめる」、`断定` は「言い切る」、`取り違える` は「順序を間違える・勘違いする」、`見落とす` は「気づかない・確認から漏れる」（何を見落とすかが明確なふだんの用法や、落とし穴の言い換えに使う「見落としやすい点」は残す）                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **役割・位置の比喩** | `入口` `土台` `道具` `核心` `主役` `構図` `線引き` `導線` `出口` `〜のカギ` `〜への近道` `〜の第一歩` `両輪` | 「〜の入口として」「〜するための土台」 | `入口` は「はじめの一歩・手始め」、`土台` は「基本・根っこ」、`道具` は「手段・やり方」、`核心` は「いちばん肝心なところ・大事な点」、`主役` は「中心」、`構図` は「全体の仕組み・関係」、`線引き` は何を区別するか、どこまでを対象にするかが分かる場合に、その内容を書く。`導線` は「誘導する流れ・経路」、`出口` は「結論・終わらせ方」、`〜のカギ` は「〜を左右する点」、`〜への近道` は「〜を早く進める方法」、`〜の第一歩` は「最初の段階・手始め」、`両輪` は「どちらも欠かせない二つ」。電気の導線、建物の出口、出口戦略のような字義どおりの用法や定着した用語、「車の両輪」「第一歩を踏み出す」のような定着した言い方、入口の言い換えに使う「はじめの一歩」は残す。 |
| **評価・結論の定型** | `別物` `定番` `要点` `定石` `桁違い` `勝ち筋` `刺さる`（汎用の評価として） `〜で決まる`                      | 「〜とは別物です」                     | `別物` は「まったく違うもの」、`定番` は「よく使われるもの」、`要点` は「大事なところ」、`定石` は「いつものやり方・標準の進め方」、`桁違い` は「段違い・はるかに大きい」、`勝ち筋` は「うまくいく見込みのある進め方」、`刺さる` は「強く響く・関心を引く」、`〜で決まる` は何によって何が決まるのかが原文から分かる場合だけそれを書き、言い切りの強さは保つ。                                                                                                                                                                                                                                                                                                              |

`実測` `照合` `突き合わせる` は技術記事で字義どおりに使う語なので、この表では扱わない。
`既定` は prh が「デフォルト」にそろえるので、この表では扱わない。

## 5. 具体的に見えて意味が曖昧な言葉

| 分類                     | 見直したい語                                                                                                     | 書き直すときの注意点                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **質感を装う語**         | `手触り` `肌感` `肌感覚` `体温` `温度感` `熱量` `血の通った` `泥臭い`                                            | 元の文や前後から分かる範囲で客観的な事実を書く。情報が足りない場合は作り話を足さず、同じ幅のふだんの言葉で書く。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **理解を曖昧に表す語**   | `解像度`（解像度を上げる/高い） `腹落ち` `メンタルモデル` `文脈` `粒度` `余白` `軸`（自分なりの軸） `言語化`     | その語が指す考えや前提を、元の文にある情報の範囲で説明する。定義された用語や、意味が明確な「文脈」などは残す。データの粒度や座標軸のような技術用語、紙面の余白のような字義どおりの用法も残す。                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **作業を曖昧に表す動詞** | `落とし込む` `紐解く`                                                                                            | 何をどうするのか（手順にする、資料にまとめる、原因を調べるなど）が原文から分かる場合だけ、その動作で書く。分からない場合は動作を推測で決めず、元の語を残す。定義された用語や、「歴史を紐解く」のように書物や記録を読み解く意味で使う定着した言い方は残す。                                                                                                                                                                                                                                                                                                                                                                                                   |
| **評価を装う語**         | `本質` `本質的` `地に足のついた` `等身大` `これは強い`（有効だという意味で）                                     | 「本質的なアプローチ」のような空疎な修飾語は削る。ただし、文の主題や論点そのものになっている語（「本質」「核心」など）を「目的」など別の概念へすり替えたり、勝手に動詞を足して文の働きを変えてはならない（「いちばん肝心な点」「大事なところ」など平易な言葉にするか、そのまま残す）。「これは強い」は、何に有効かが原文から分かる場合だけ「〜に有効だ」のように書き、分からなければ元の言い方のまま残す。                                                                                                                                                                                                                                                   |
| **未定義造語**           | `意思決定OS` `思考のOS` などの勝手な比喩命名                                                                     | ふだん使う平易な言葉や客観的な機能説明で書く（硬い漢語を並べない）。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **役割を大げさに呼ぶ語** | ルールを指す `契約`、原文や比較の基準を指す `正本`、ただの確認手順を指す `ゲート`、ただの記録や一覧を指す `台帳` | 「ルール」「方針」「原文」「比較の基準」「参照するファイル」「確認」「チェック」「記録」「一覧」等、実際の役割に合う語へ直す。取引・合意としての契約、正式な文書を区別する正本、正式名称としての品質ゲート、会計・行政の台帳、定義された専門用語の意味は保つ。                                                                                                                                                                                                                                                                                                                                                                                               |
| **指す内容が曖昧な名詞** | 手段や書き方を曖昧に呼ぶ `仕組み`、何を区別するかが曖昧な `境界`                                                 | 何を行うか、何を区別するかが分かる範囲で書く。実際の処理を説明する「仕組み」や、数学・区域の境界、境界値、定義された用語や実際の名称は保つ。「この境界を守れば問題を防げる」のように語の指す対象が曖昧でも、「守れば問題を防げる」という動作や関係は分かる。語の対象を決めることと条件付きの主張を本文に残すことは別であるため、元にない仕組みを推測で書き足さず、元の条件付き主張と言い切りの強さをそのまま本文に残す（「防げるとされている」のような批評や伝聞には変えない）。本文や確認の問いでも、不明な語が何を指すかを推測で前提にせず、時点・責務・範囲・判断条件などの種類や役割を勝手に限定しない。不明な語の確認は「書き手に確かめたい点」で行う。 |

## 6. 不要な前置きと定型の結び

| 分類                   | 見直したい表現                                                                                                                                                                                                                                                                               | 書き直すときの注意点                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **前置フィラー**       | `重要なのは` `大切なのは` `結論から言うと` `結論から言うね` `結論から言います` `正直に言うと` `本音を言うと` `原因はシンプルです` `避けたいのは` `ここで注目すべきは` `ここが一番見落とされがち` `まさにそこがポイント` `もちろん、〜。`（文頭の「もちろん、」のあとに数語だけが続く短い文） | 単なる前置きは削る。「結論から言うと」などの前置きは、続く結論が抽象的で、本文で同じ結論を言い直している場合に削る。報告書のように結論を先に置く構成そのものは変えない。評価は述語へ移して保つ。理由・対比・結論や文の働きの切替を示す場合は、その関係を残す。比較から採用方針へ移る「結論として」などを、語だけで不要と判定しない。文頭の「もちろん、」のあとに数語だけが続いて終わる短い文で、読み手が思いそうなことを先回りして認めているものは、「もちろん、」を外す。含みを別の語で補わず、認めている内容とその程度は残し、元にない理由や因果やつなぎの語は足さない。会話や引用の中、問いや依頼への答え、条件や前提を確かめる文、「もちろん、」の後に同じ文の中で具体的な内容が続く文、「AはもちろんB」の形は残す。 |
| **定型導入**           | `本記事では〜をご紹介します` `それでは見ていきましょう` `深掘りしていきます` `ここまで見てきました` `次の章では〜を説明します`                                                                                                                                                               | 続く本文と同じ内容を予告したり振り返ったりしているだけの案内は、続く中身の文と1文にまとめられればまとめ、本文と重なるだけなら削る。長いマニュアルの目次的な案内や、扱う範囲・前提・対象読者を示す文、「この表の読み方は次のとおりです」のように続く箇条が何の一覧かを示す文は残す。                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **数の宣言**           | `重要なポイントは3つです` `理由は3つあります` `以下の3つの観点から説明します`                                                                                                                                                                                                                | 宣言の数と続く項目の数が合っている場合だけ、続く中身とまとめる。長い説明で、項目数の予告が読み手の案内になっている場合は残す。数が合わない場合も、宣言の数と項目を変えない。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **文末の付け足し**     | `〜というわけです` `〜に他なりません` `〜と言えるでしょう` `面白いのはここです` `驚くべきことに`                                                                                                                                                                                             | 原文の説明・評価・推量を、その働きと強さを保って書く。段落の終わりごとに同じ推量の結びが続いて読みにくい場合も、推量の強さと掛かる範囲は保ち、語順や言い回しで繰り返しを整える。文末をそろえるために評価を事実へ変えたり、推量を断定へ上げたりしない。                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **言い直しの締め**     | `まとめると` `結局のところ` `要するに` `総じて`、本文の繰り返しだけの「まとめ」見出しと段落                                                                                                                                                                                                  | 本文で言い終えた内容を同じ強さで繰り返すだけなら、その文や段落、見出しを削る。新しい情報、条件、結論の絞り込み、長い文書の要約を担う場合は残す。その箇所にしかない数値・条件・例外は落とさない。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **チャット応答の名残** | `ご質問ありがとうございます` `おっしゃる通りです` `必要なら次に〜します` `ご希望があれば〜できます` `〜を知りたいですか？`                                                                                                                                                                   | 記事や文書の本文に、チャットの返答の書き出しや申し出、同意・共感の定型が残っている場合は削る。チャットの返信そのものを推敲する場合や、書き手が読者に実際に申し出ている場合は残す。読み手への実際の同意・共感や、会話・引用は、語の形だけで削らない。                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **定型の結び**         | `いかがでしたでしょうか` `ぜひ試してみてください` `〜の参考になれば幸いです` `お役に立てれば幸いです` `ぜひご活用ください` `まずは小さく始めましょう`                                                                                                                                        | 意味を担わない定型の呼びかけを削り、本文の自然な結びで終わる。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **仮置きの残り**       | `〇〇` `XXX` `[ここに〜を入れる]` `【要確認】`                                                                                                                                                                                                                                               | 公開・提出する文に残った仮の文字は、入れる値が原文・依頼・提供資料に明示されている場合だけ置き換える。分からなければ推測で埋めたり削ったりせず、「書き手に確かめたい点」で尋ねる。会話や引用の中の伏せ字（「〇〇さんに聞かないと分からない」など）、例として書いた「〇〇」、意図的なテンプレートは残す。                                                                                                                                                                                                                                                                                                                                                                                                                 |

## 7. 硬い漢語と決まり文句

| 分類                 | 見直したい表現                                                       | 書き直すときの注意点                                                                                                                                                                                                                                                                                                                                                                                                  |
| -------------------- | -------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **硬い漢語**         | `活用する` `実施する` `多角的` `包括的` `〜を実現することができます` | `活用する` は「使う」（生かすという含みが要る場合は「生かす」）、`実施する` は「行う」「する」、`〜を実現することができます` は「〜できます」（「高速化を実現することができます」は「高速化できます」。動作を表す語でない場合は「〜を実現できます」にとどめる）。`多角的` `包括的` は、どの観点やどの範囲で見るのかが原文から分かる場合だけ、その観点や範囲を書く。分からない場合は観点を推測で足さず、元の語を残す。 |
| **決まり文句**       | `シームレス` `シナジー` `価値を最大化` `次のレベルへ`                | 何がどう変わるのかが原文から分かる場合だけ、その内容で書く。分からない場合は効果を推測で足さず、元の語を残す。製品の機能名や定義された用語は残す。                                                                                                                                                                                                                                                                    |
| **誇張語**           | `圧倒的` `爆速` `革命的` `徹底解説`                                  | 数値の裏付けがある場合や、書き手の実感として書いている場合は残す。本文の内容と釣り合わない誇張だけを、評価の向きを保ってふだんの言葉にする。元にない数値や比較を足さない。                                                                                                                                                                                                                                            |
| **論文調の言い回し** | `〜ことを示している` `〜ことが知られている`                          | 論文や報告書で、データや出典を根拠に示している文は残す。学術的でない文章で何が何を示すのかがぼやけている場合だけ、示している主体（「この結果は」など）と内容を述語までつないで書く。根拠と言い切りの強さ、文の種類（事実か伝聞か）は変えない。                                                                                                                                                                        |
| **機械的なつなぎ**   | `これにより`                                                         | 前後の文に因果がはっきりしないのに、結果を機械的につないでいる場合だけ見直す。施策と効果のように、前の文の内容から後ろの結果が生じる関係が読み取れる「これにより」は残す。つなぐ関係が分からなければ、元にない因果を作らずに原文を残す。                                                                                                                                                                              |
